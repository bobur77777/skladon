# Skladon

Офлайн-first веб-приложение для учёта товаров, продаж и остатков. Работает в браузере компьютера и телефона, данные сохраняются локально в `localStorage` и не требуют интернета. Валюта приложения — узбекский сум.

## Запуск

Откройте `index.html` в браузере. Для полноценной установки PWA и работы service worker используйте любой локальный статический сервер, например:

```bash
python -m http.server 8080
```

Затем откройте `http://localhost:8080`.

## Возможности

- пустой каталог для самостоятельного добавления бытовых товаров, компьютерной техники, оргтехники и телефонов;
- себестоимость, обычная и минимальная цена продажи;
- продажи с автоматическим уменьшением остатков и расчётом прибыли;
- продажи в долг с покупателем, датой возврата, напоминанием о просрочке и отметкой погашения;
- контакты должника: имя, телефон и адрес;
- отдельное приложение продавца (`seller.html`) только для просмотра каталога и оформления продаж;
- отчёт продавца по дням с общей выручкой и доходом от продаж;
- уведомления продавцу о долгах, срок которых наступил или приближается;
- погашенные долги исключаются из уведомлений, срочных долгов и общей задолженности;
- фильтр продавца по категории, виду товара и модели, например «Бытовые товары → Телевизор → модель»;
- удаление отдельных товаров из каталога с сохранением истории продаж;
- статистика добавления и удаления товаров в журнале администратора;
- полное удаление демо-сброса: каталог изменяется только точечно, а журнал добавлений и удалений не имеет кнопки очистки;
- логин и пароль продавца настраиваются администратором в разделе «Настройки»;

Учётные данные продавца хранятся локально в браузере для офлайн-режима. Это подходит для работы на одном компьютере; для защиты при работе через сеть в будущем потребуется серверная авторизация.
- приход, расход и инвентаризация с историей движений;
- отчёт по общим остаткам с количеством единиц, себестоимостью склада и сохранением в PDF через печать браузера;
- дашборд;
- JSON-резервная копия для переноса на телефон;
- PWA-кэш для работы без интернета.

При каждой операции данные сразу записываются в локальное хранилище браузера. Не очищайте данные сайта, если хотите сохранить учёт. Для переноса на другой компьютер или телефон используйте JSON-резервную копию в разделе «Настройки».

Слой данных изолирован в `app.js`; для будущей синхронизации его можно заменить на IndexedDB/API без изменения экранов и бизнес-операций. При работе через `http://localhost` или HTTPS сервис-воркер кэширует приложение, поэтому оно открывается без интернета после первого запуска.
